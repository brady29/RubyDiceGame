SEQUENCE DIAGRAMS
---------------------------------------------------------------------
All diagrams are SVG (vector graphics) files in the docs/ folder.
Attribution: all four sequence diagrams were generated by Claude
(Anthropic's AI assistant) for this assignment.

  SD1_PlayGame.svg
    Use case: Play Game
    Purpose:  Run a complete automatic game, from validating the
              settings and creating the players to announcing the winner.

  SD2_TakeTurn.svg
    Use case: Take Turn
    Purpose:  Let the current player keep rolling until a 2 or a 5 appears,
              then pass play to the next active player.

  SD3_RollDice.svg
    Use case: Roll Dice
    Purpose:  Roll a player's remaining dice once, score the roll (sum of
              the faces, or nothing if a 2 or 5 shows), write the points on
              the score sheet and remove every die showing a 2 or a 5.

  SD4_DropDeadAndWin.svg
    Use case: Player Drops Dead / Determine Winner
    Purpose:  Remove a player who has no dice left, end the game when no
              players remain, and choose the player(s) with the most points.


CLASS DESCRIPTIONS
---------------------------------------------------------------------

=====================================================================
Class: Die
Single responsibility: Produce a random face value for one die.

Instance variables
  @sides   Integer - number of faces on the die (at least 6)
  @random  Random  - random number generator used to roll
  @value   Integer - face showing after the last roll (nil before rolling)

Public methods
  initialize(sides, random = Random.new)
    Creates a die with the given number of sides. Raises ArgumentError if
    sides < 6.
    Responsibility: build a valid die.
  roll -> Integer
    Rolls the die and returns the face that came up (1..sides).
    Responsibility: generate a new random face.
  sides -> Integer
    Responsibility: report how many sides the die has.
  value -> Integer or nil
    Responsibility: report the face currently showing.
  to_s -> String
    Responsibility: give a printable form of the face showing.

=====================================================================
Class: DiceCup
Single responsibility: Manage the collection of dice a player still owns.

Instance variables
  @dice  Array<Die> - the dice the player has not yet lost

Public methods
  initialize(dice_count, sides, random = Random.new)
    Fills the cup with dice_count dice, each with the given sides.
    Responsibility: build the player's starting set of dice.
  roll_all -> Array<Integer>
    Rolls every die in the cup and returns the faces.
    Responsibility: roll all remaining dice together.
  remove_if { |face| ... } -> Integer
    Removes every die whose face makes the block return true and returns
    how many were removed.
    Responsibility: take dice out of the cup.
  count -> Integer
    Responsibility: report how many dice are left.
  empty? -> Boolean
    Responsibility: report whether the cup has no dice left.

=====================================================================
Class: RollEvaluator
Single responsibility: Apply the Drop Dead scoring rules to a roll.

Instance variables
  (none) - the dead faces are held in the constant DEAD_FACES = [2, 5]

Public methods
  dead_face?(face) -> Boolean
    True when the face is a 2 or a 5.
    Responsibility: decide whether a single die is lost.
  contains_dead_face?(faces) -> Boolean
    True when any face in the roll is a 2 or a 5.
    Responsibility: decide whether a roll ends the turn.
  score(faces) -> Integer
    Sum of the faces, or 0 when the roll contains a 2 or a 5.
    Responsibility: compute the points a roll is worth.

=====================================================================
Class: ScoreSheet
Single responsibility: Record and total a player's points (the player's
"paper").

Instance variables
  @entries  Array<Integer> - points written down, one entry per scoring roll

Public methods
  initialize
    Starts an empty sheet.
    Responsibility: create a blank score sheet.
  record(points) -> Array<Integer>
    Writes the points from one roll onto the sheet.
    Responsibility: store a score.
  total -> Integer
    Adds up every entry on the sheet.
    Responsibility: tally the points.
  entries -> Array<Integer>
    Returns a copy of the recorded entries.
    Responsibility: expose the score history without allowing changes.

=====================================================================
Class: RollResult
Single responsibility: Describe the outcome of a single roll (value object).

Instance variables
  @faces         Array<Integer> - faces that came up
  @points        Integer - points earned by the roll
  @dice_removed  Integer - number of dice lost (2s and 5s)
  @dice_left     Integer - dice the player still has after the roll

Public methods
  initialize(faces, points, dice_removed, dice_left)
    Builds a frozen record of the roll.
    Responsibility: capture a roll's outcome.
  faces, points, dice_removed, dice_left
    Readers for the values above.
    Responsibility: report one fact about the roll.
  scored? -> Boolean
    True when no dice were removed, so the player rolls again.
    Responsibility: say whether the turn continues.
  dropped_dead? -> Boolean
    True when the roll took the player's last die.
    Responsibility: say whether the player is out.

=====================================================================
Class: Player
Single responsibility: Represent one participant and carry out their
rolls.

Instance variables
  @name         String        - display name, e.g. "Player 1"
  @dice_cup     DiceCup       - the dice the player still owns
  @score_sheet  ScoreSheet    - the points the player has written down
  @evaluator    RollEvaluator - the rules used to judge each roll

Public methods
  initialize(name, dice_cup, evaluator = RollEvaluator.new)
    Creates a player with their dice and a blank score sheet.
    Responsibility: set up a participant.
  roll -> RollResult
    Rolls the remaining dice once, records any points and removes 2s and 5s.
    Responsibility: perform one roll for this player.
  dice_left -> Integer
    Responsibility: report how many dice the player has.
  alive? -> Boolean
    True while the player still has at least one die.
    Responsibility: report whether the player is still in the game.
  total_score -> Integer
    Responsibility: report the player's points.
  name -> String, score_sheet -> ScoreSheet, to_s -> String
    Responsibility: identify the player / expose their sheet.

=====================================================================
Class: Turn
Single responsibility: Play out one player's turn.

Instance variables
  @player  Player            - whose turn it is
  @rolls   Array<RollResult> - every roll made during the turn

Public methods
  initialize(player)
    Prepares a turn for the player.
    Responsibility: start a turn.
  play { |result| ... } -> Array<RollResult>
    Rolls repeatedly until a roll contains a 2 or a 5, yielding each result.
    Responsibility: apply the "keep rolling until a 2 or 5" rule.
  rolls -> Array<RollResult>
    Responsibility: report the rolls made this turn.
  points -> Integer
    Responsibility: report the points earned this turn.
  player -> Player
    Responsibility: identify whose turn it is.

=====================================================================
Class: DropDeadGame
Single responsibility: Track the players still in the game and whose turn
it is.

Instance variables
  @players         Array<Player> - everyone who started the game
  @active_players  Array<Player> - players who have not dropped dead
  @current_index   Integer       - position in @active_players of the next
                                   player to take a turn

Public methods
  initialize(players)
    Starts a game with the given players. Raises ArgumentError if empty.
    Responsibility: set up the table.
  players -> Array<Player>
    Responsibility: report everyone in the game.
  active_players -> Array<Player>
    Responsibility: report who is still playing.
  current_player -> Player or nil
    Responsibility: report whose turn is next.
  over? -> Boolean
    True when no players are left.
    Responsibility: decide whether the game has ended.
  play_next_turn { |result| ... } -> Turn
    Plays the current player's turn, removes them if they drop dead and
    moves on to the next player.
    Responsibility: advance the game by one turn.
  winners -> Array<Player>
    The player(s) with the highest total (several when tied).
    Responsibility: decide who won.

=====================================================================
Class: GameTranscript
Single responsibility: Write a readable account of the game as it happens.

Instance variables
  @output  IO - where the transcript is written (default $stdout)

Public methods
  initialize(output = $stdout)
    Responsibility: choose where the transcript goes.
  game_started(sides, dice_count, players)
    Responsibility: print the game settings.
  round_started(round, players)
    Responsibility: print a round header.
  turn_started(player)
    Responsibility: print the player's dice and points before their turn.
  roll_made(result)
    Responsibility: print one roll and what it did.
  turn_ended(turn)
    Responsibility: print the turn summary, or that the player dropped dead.
  game_ended(players, winners)
    Responsibility: print the final scores and the winner(s).

=====================================================================
Class: AutoDropDead
Single responsibility: Play a complete game automatically, with the
computer controlling every player.

Instance variables
  @transcript  GameTranscript - reports the game as it is played
  @random      Random         - shared random generator for every die

Public methods
  initialize(output = $stdout, random = Random.new)
    Responsibility: configure where output goes and the source of randomness.
  play_game(sides, dice_count, player_count) -> Array<Player>
    Validates the settings (sides >= 6, dice_count >= 2,
    player_count >= 1; otherwise ArgumentError), creates the players,
    plays rounds until everyone has dropped dead, prints the transcript and
    returns the winner(s).
    Responsibility: run one full automatic game.
